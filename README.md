# FinStake

Адаптивный frontend независимого агентства кредитного брокерства. React + TypeScript + Vite, обычный CSS, Motion, Lucide, локальные Manrope и WebP-фотографии. Внешние сервисы, аналитика и CRM по умолчанию не подключены.

## GitHub Pages

Адрес: https://spayzik.github.io/finstake/

Workflow `.github/workflows/pages.yml` проверяет тесты, собирает сайт командой `npm run build:pages` с base `/finstake/` и публикует его после push в `main`. Локальный `npm run build` сохраняет обычный base `/`. Изображения учитывают `import.meta.env.BASE_URL`; ссылки внутри страницы остаются якорными.

Статическая публикация сохраняет деморежим заявок. Калькулятор работает целиком в браузере. API/CRM и банковская витрина не подключены. Папка `evidence/` с локальными снимками, логами и референсами не публикуется в Git; исходники, runtime-ассеты и документация входят в репозиторий.

## Запуск

Нужен Node.js 22.12+; проверено на Node.js 24.18.0.

```powershell
npm ci --ignore-scripts
npm run dev
```

Локальная разработка: http://127.0.0.1:4187. Порт закреплён, чтобы случайно не открыть другой проект на обычном 5173.

```powershell
npm test
npm run build
npm run preview
```

Production preview: http://127.0.0.1:4189. Собранный сайт находится в `dist/`. Для хостинга нужен обычный статический сервер; относительные якоря работают без маршрутизатора. Сервер обработки заявок подключается отдельно.

## Что работает

- Навигация по реальным разделам, закреплённая шапка и мобильное меню.
- Четыре направления с предвыбором услуги в форме.
- Четырёхэтапное сопровождение до получения кредита, блок «Сначала — результат. Потом — оплата» и FAQ с клавиатурным управлением.
- Рабочий локальный калькулятор: сумма, срок, ставка, равные/убывающие платежи, проценты и полный график. Параметры переносятся в заявку.
- Двухшаговая форма, inline-ошибки, сохранение данных при возврате, закрытие Escape, удержание и возврат фокуса.
- По умолчанию **деморежим**: форма проверяет данные локально и сообщает, что заявка не отправлена. Данные хранятся только в памяти компонента до закрытия.
- Подготовлен отдельный API-адаптер с ожиданием, повтором после ошибки, отменой/тайм-аутом и строгой проверкой фактического HTTP 201.
- Reduced motion предусмотрен в Motion и CSS. Нет бесконечных декоративных анимаций, скролл-джекинга и прелоадеров.

## Документы

- `DESIGN.md` — позиционирование, выбранное направление, reference lock, токены, сетка, адаптивность и критерии приёмки.
- `ASSETS.md` — источники, авторы, лицензия, размеры и SHA-256 фотографий.
- `docs/LEAD_API.md` — контракт и отдельное включение реальной отправки.
- `evidence/v2/QA.md` — текущие проверки новой версии; `evidence/QA.md` сохраняет результаты первой версии.
- `evidence/` — снимки разных экранов и состояний.

## Локальная проверка серверных состояний

```powershell
node scripts/qa-server.mjs
```

Только тестовая заглушка на http://127.0.0.1:4188 с заметной подписью. Использовать исключительно синтетические данные. Комментарий `qa:error` даёт задержанный HTTP 503; `qa:invalid` — HTTP 200 без допустимого подтверждения; любой другой комментарий — синтетический HTTP 201 с `LOCAL-QA-001`. Ничего не сохраняется и не пересылается. Это не backend для реальных обращений и не юридическая политика.

## Перед публичным запуском

Нужны исходный вектор логотипа для точной сверки, реальные контакты и сведения об операторе, утверждённые политика/согласие и API приёма заявок. Знак и двухцветное написание FinStake восстановлены по предоставленным визуальным референсам. Юридическое лицо, адрес, телефон, реквизиты, отзывы и кредитные гарантии не выдуманы. Владелец подтвердил отсутствие предоплаты и оплату после получения кредита; это отражено в текстах и FAQ. Размер вознаграждения не указан.

Три скриншота получены во втором сообщении и визуально изучены: `evidence/references/`. Новая версия использует панорамный hero из референса 02, изумрудную палитру, объёмные glass-панели и светлые компактные поверхности. Фон hero создан встроенным imagegen как иллюстративная архитектурная визуализация без людей; это не фотография реального офиса FinStake. Исходные фотографии и доказательства первой версии сохранены.

Refero MCP ранее вернул `NO_SUBSCRIPTION`; закрытые экраны не просматривались. Доступные 21st.dev, Kokonut и Lusion просмотрены визуально в первой итерации. Код сторонних UI-компонентов не скопирован.

## Калькулятор и банковские данные

Текущий расчёт выполняется в браузере по введённой ставке. Он не использует AI, не обращается к Банки.ру и не показывает действующие предложения банков. Первоначальная ставка — пример для расчёта, а не рыночная котировка. Страхование, комиссии и вознаграждение брокера не включены; это указано рядом с результатом. Методика: `docs/CALCULATOR.md`.

После уточнения владелец выбрал расчёт без банковской витрины. Партнёрские API/публичный сбор банковских данных — отдельная будущая интеграция с проверкой доступа, прав на использование и свежести. В проекте нет ключей AI, скрытого парсера или вымышленных банковских ставок.
